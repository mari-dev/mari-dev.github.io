# mari-dev.github.io

Ready-to-publish static portfolio for GitHub Pages.

## Publish

1. Create a public repository named exactly `mari-dev.github.io`
2. Put these files in the repository root
3. Push to `main`
4. Open GitHub → Settings → Pages
5. Choose **Deploy from a branch**
6. Select `main` and `/ (root)`

Your site should then be available at:

`https://mari-dev.github.io/`

## Files

- `index.html` — page content
- `styles.css` — design and responsive layout
- `assets/hero.png` — hero illustration

No build system is required.
